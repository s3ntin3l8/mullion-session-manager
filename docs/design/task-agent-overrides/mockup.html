Task sidebar — agent & model overrides

The redesign dropped five per-task controls: Agent, Review agent, Model, Small model (opencode/claude only) and Reviewer model (hidden for Hermes/none). The backend still accepts them via PATCH /api/tasks/:id. Details gets a Worker/Reviewer summary showing the effective value and where it comes from (task override, issue directive or project default). Two ways to edit. Mock data is fictional.

Rules both options share
  • Editable only in backlog, ready-and-unclaimed, or failed (same rule as before). Otherwise rows are read-only with the lock hint.
  • Every change saves immediately; a failed save shows an inline error.
  • First entry of each dropdown is “Default (<resolved>)” and clears the override. A dot marks a row that carries a task override.
  • opencode: a provider dropdown then a model dropdown; other CLIs: the Agent is the provider.
  • Changing the agent family clears a model chosen for the old family.
